# psychometric-tools

<p align="center"><a href="https://doi.org/10.5281/zenodo.19163768"><img src="https://zenodo.org/badge/DOI/10.5281/zenodo.19163768.svg" alt="DOI 10.5281/zenodo.19163768" /></a></p>

psychometric-tools is a static web landing that unifies access to related statistical tools.

It provides:

- a single entry point for multiple tools,
- a consistent UI shell and navigation,
- language and theme controls,
- direct access to each tool page.

Web version:

- https://enheragu.github.io/psychometric-tools/

Documentation:

- i18n policy: `docs/i18n-policy.md`

## How to cite

If you use these tools, please cite them: the metadata are in [`CITATION.cff`](CITATION.cff), and GitHub's
*Cite this repository* button exports them as APA or BibTeX. The DOI
[10.5281/zenodo.19163768](https://doi.org/10.5281/zenodo.19163768) always resolves to the latest release;
each release also has its own DOI (v1.0.0: [10.5281/zenodo.19163769](https://doi.org/10.5281/zenodo.19163769)),
which is the one to cite when reporting results obtained with that version.
